## ⚙️ Configuration

- Raise bitrate only while latency and dropped frames stay stable.
- Use HEVC or AV1 when both ends support it; fall back to H.264 for compatibility.
- Disable vsync on the client and enable the low-latency option.
- Match the stream refresh rate to the client display.

## 🚀 Performance Tips

- Wired Ethernet on both ends beats Wi-Fi for GTA 6 driving and chases.
- Leave 10 to 15 percent GPU headroom for encoding.
- Test with a fast drive through traffic, not a static menu.
- Keep the console and router out of congested 2.4 GHz channels.

## 🔧 Troubleshooting

| Symptom | Fix |
| --- | --- |
| Input lag | Use wired Ethernet, lower the bitrate and disable client post-processing. |
| Black screen or failed connection | Check the firewall, ports and that both devices are on the same subnet. |
| Controller not detected | Pair the controller before starting the stream and test it in the client. |
| Audio crackle or desync | Set the same sample rate on both ends and disable audio enhancements. |
| Installer blocked by SmartScreen | Right-click setup.exe, open Properties, tick Unblock, then run it again. |
| Installer cannot find GTA 6 | Point the wizard to the game folder or console client and run it as administrator. |

## ❓ Frequently Asked Questions

**Do I need a capture card for GTA 6 on PC?**

No. Network Remote Play sends the console video directly; a capture card is only for HDMI capture and streaming.

**Can I play GTA 6 on PC over the internet?**

Yes, with port forwarding or a VPN, but local wired streaming is faster and more stable.

**Is GTA 6 available natively on PC?**

At the time of writing GTA 6 is console-only. This guide covers the Remote Play chain, not a native PC port.

**Does HDR work through Remote Play?**

Only when the console, client and display all support HDR and the option is enabled on both ends.

**What does the installer change?**

It installs the recommended client or tool and applies a tested GTA 6 profile. It does not modify GTA 6 game files.

**How do I uninstall it?**

Run uninstall.exe from the install folder or use Windows Apps, then restore the previous profile if needed.
